1. Overview

The declarations themselves live in lib/system/ascii.z, which is the one place they are written, each with its doc comment. This page is the prose.

ascii names the ASCII bytes that a character literal cannot spell. A character literal is one identifier token that starts with 0c, so it writes any byte an identifier may hold -- 0cA, 0c/, 0c_ -- and the escapes 0c\n, 0c\t, 0c\b, 0c\\ and 0c\x20. The space and the delimiters end an identifier, and most control bytes have no escape. Those bytes have a name here. Each name is a u8 constant.

2. Index

  • nul 0, bs 8, ht 9, lf 10, cr 13, del 127 -- the control bytes, under their ASCII mnemonics
  • space 32
  • doubleQuote 34, hash 35, backtick 96
  • parenOpen 40, parenClose 41, bracketOpen 91, bracketClose 93, braceOpen 123, braceClose 125
  • comma 44, dot 46, colon 58, semicolon 59

3. Which spelling to write

  • A byte an identifier may hold is a character literal: 0c/, 0c0, 0c_.
  • A control byte that has an escape is that escape: 0c\n, 0c\t. The others are named: ascii.cr, ascii.nul.
  • The space and a delimiter are named: ascii.space, ascii.comma, ascii.braceOpen.
  • A byte that is only appended to a text is written as text: buf.append ",".
# count the fields of one comma-separated line
fields: function {line: StringView} out u64 is {
    n: 1.u64
    for each b: line.byteView loop {
        if b == ascii.comma then n = n + 1
    }
    return n
}

main: function is {
    print "\{fields line: "a,b,c"}"   # 3
}
