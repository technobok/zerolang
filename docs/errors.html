1. Error codes

Every error the compiler reports has a code, E and four digits, and the first line of a diagnostic names it (error[E0200]: ...). The codes are grouped by range: Error Code Numbering says which range is which stage. zc explain E0200 prints a code's meaning and a longer description.

The table gives each code's meaning, as zc explain gives it. A section for each code follows, with a program that the compiler refuses with that code; the documentation's checks compile each one and require that code as its first error.

2. E0002

file not found. The source file of a unit could not be found under the source roots or the system library. A single file cannot show it: zc build nosuch, in a directory with no nosuch.z, reports it.

$ zc build nosuch
error[E0002]: file not found

3. E0003

duplicate definition. Two definitions in one scope share a name.

limit: 5
limit: 6

main: function is {
    print "\{limit}"
}

4. E0004

bad unit name. A unit's name is not an identifier. A file's name gives its unit's name, so a file cannot show it: a file named bad-name.z is refused.

$ zc build bad-name
error[E0004]: Invalid unit name

5. E0005

malformed unit. Something other than a definition stands at the top level of a unit: here a closing brace with no opening one.

main: function is { print "a" }
}

6. E0007

I/O error. Reading or writing a file failed: a source root that is not a folder, a file that cannot be read. A single file cannot show it.

7. E0009

unexpected characters. The characters form no token of the language: here a run of two dots.

main: function is {
    x: 1 .. 2
    print "\{x}"
}

8. E0010

expected a definition. The parser expected a label: here for each with no name for the element.

main: function is {
    xs: ListVal i64
    for each xs.iterate loop print "x"
}

9. E0012

expected an expression. The parser expected an expression: here a with label with no value.

main: function is {
    with x: do print "a"
}

10. E0013

expected an operator. The parser expected an operation: here an if with no condition.

main: function is {
    if then {
        print "x"
    }
}

11. E0014

expected a type definition. The parser expected a type definition or a value: here a label with nothing after it.

x:
main: function is { print "a" }

12. E0015

expected a statement. The parser expected an expression in a body: here a closing parenthesis.

main: function is {
    if true then )
}

13. E0017

malformed argument. A function's signature is not well formed: here it declares both out and outx.

mk: function out i64 outx i64 is {
    return 1
}

main: function is {
    print "\{mk}"
}

14. E0019

malformed expression. An expression is not well formed: here a parenthesis that does not close.

main: function is {
    x: (1 + 2
    print "\{x}"
}

15. E0021

malformed string. A string literal is not well formed: here an escape the language does not have.

main: function is {
    s: "bad \q escape"
    print s
}

16. E0022

malformed path. A path is not well formed: here a field read after .take, which ends a path.

pt: class { a: i64 }

main: function is {
    p: pt a: 3
    q: p.take.a
    print "\{q}"
}

17. E0023

malformed reference. A name refers to nothing in scope.

main: function is {
    print missing
}

18. E0025

malformed parameter. A parameter is not well formed: here two parameters share a name.

f: function {a: i64 a: i64} is { print "a" }

main: function is { f a: 1 }

19. E0026

malformed parameter block. A parameter block is not well formed: here it does not close with a brace.

f: function {a: i64 )} is { print "a" }

main: function is { f a: 1 }

20. E0027

malformed object block. An object body is not well formed: here a record's body does not close.

R: record {
    a: i64

main: function is { print "a" }

21. E0028

malformed item. An item of a definition is not well formed: here a variant is is native and has an is-block too.

tri: variant is native { lo: null mid: null }

main: function is {
    t: tri.lo
    match (t) case lo then print "lo" case mid then print "mid"
}

22. E0029

malformed then clause. A then clause is not well formed: here it holds a bare if, which needs braces.

main: function is {
    a: 0
    b: 5
    if b > 3 then if b > 99 then a = 1 else a = 2
    print "a=\{a}"
}

23. E0031

malformed case clause. A match is not well formed: here it has no case.

color: variant {
    red: null
    green: null
}

k: match color.red

main: function is {
    print "done"
}

24. E0032

malformed for header. A for header is not well formed: here it has no condition and no loop.

main: function is {
    for { print "a" }
}

25. E0033

reserved word used as a name. A reserved word is used as a name: here the parameter take.

f: function {take: i64} out i64 is { return take }

main: function is { print "\{f take: 1}" }

26. E0034

malformed list. A list is not well formed: here an empty list that does not name its type.

none: list {}

main: function is {
    print "\{none.length}"
}

27. E0035

malformed statement. A statement is not well formed: here a bare if as the argument of return.

pick: function {c: bool} out i64 is {
    return if c then 1 else 2
}

main: function is {
    print "\{pick c: true}"
}

28. E0036

non-exhaustive match. A match handles fewer arms than its subject can hold, and has no else.

color: variant {
    red: null
    green: null
}

describe: function {c: color} is {
    match (c) case red then print "red"
}

main: function is {
    describe c: color.green
}

29. E0037

reserved member name. A member uses a reserved name: here public:, which must introduce a unit definition.

box: class {
    public: 0
}

main: function is {
    print "unreachable"
}

30. E0039

no main. The program declares no main. The documentation checks its examples as libraries, which need none, so this one is shown and not checked: zc build of this unit reports it.

double: function {n: i64} out i64 is {
    return n * 2
}

31. E0040

malformed main. main declares a parameter, and the runtime has none to pass it. A program reads its command line through os.args.

main: function {args: (List String).view} is {
    print "n=\{args.length}"
}

32. E0041

not data in a data file. A data file holds something that is not data: here an operator expression. See zdata.

sum: 1 + 2

33. E0042

nested or chained too deep. The source nests or chains deeper than 500 levels. An example would be a line of 500 operations, so none is shown.

34. E0100

type error. A type rule is broken: here bool has no +.

main: function is {
    x: true + 1
    print "\{x}"
}

35. E0101

member not public. A member its unit does not make public is read from outside the unit.

shapes: unit {
    public: unit { :area }
    area: function out i64 is { return 4 }
    secret: function out i64 is { return 7 }
}

main: function is {
    print "\{shapes.secret}"
}

36. E0102

private escape. A parameter takes a .private handle, and a plain value is given.

Bag: class { a: i64 count: i64 } as {
    public: unit { :count }
}

friendRead: function {h: Bag.private.borrow} out i64 is { return h.a }

main: function is {
    b: Bag a: 42 count: 3
    print "\{friendRead h: b}"
}

37. E0103

used before it is initialised. A local is used inside its own definition, before it holds a value.

main: function is {
    n: n + 1
    print "\{n}"
}

38. E0200

ownership error. An ownership rule is broken: here a string is read after it was moved.

main: function is {
    s: "a".string
    t: s.take
    print s
    print t
}

39. E0300

call error. A call is not well formed: here an argument names no parameter.

f: function {a: i64} is { print "\{a}" }

main: function is {
    f b: 1
}

40. E0400

generic error. A generic instantiation is not well formed: here two arguments give the same parameter.

main: function is {
    x: ListVal i64 t: f64
}

41. E0500

emitter error. The C backend cannot emit what the program needs: a construct it has no route for, or a unit whose needs the chosen C compiler lacks -- here f128, which tcc does not have. zc build --cc tcc of this program reports it; the documentation compiles with the default compiler, so it is shown and not checked.

main: function is {
    x: 1.5.f128
    print "\{x}"
}

42. E0501

no native implementation. An is native declaration has no row in its unit's nativec.zd. A native unit is a .z file and its nativec.zd, so a single file cannot show it; see Native Units.

43. E0600

compile-time evaluation error. A value the compiler computes while it compiles cannot be computed: here a division by a constant zero.

half: 10 / 0

main: function is {
    print "\{half}"
}

44. E0601

compile-time error. The program's own error fires while the compiler decides a condition it can compute.

mode: 0

main: function is {
    if mode == 0 then error "mode must not be zero"
}
