# msvc-known-failures.txt -- the RUN cases make test-msvc-corpus expects to fail
# when MSVC (cl) builds them, as "<name> (<step>)". Delete a line in the commit
# that makes its case pass.
#
#   (zc)     zc refuses the program before any C is compiled, naming the unit
#            and what it needs: cl has no __float128, which f128 is built on.
#            This is the finished state.
#   (posix)  the case needs a POSIX facility that Windows has none of.
#   (cc)     cl rejects the emitted C.
