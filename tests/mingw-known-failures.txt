# RUN cases that do not pass when built for Windows by mingw-w64 (zc --target
# x86_64-w64-mingw32) and run under wine. Read by `make test-mingw`. One line
# per program: `<name> (<stage>)`.
#
#   (cc)   the emitted C does not compile or link for Windows: a native the
#          program reaches calls POSIX with no Win32 counterpart.
#   (posix) it checks something only POSIX has (run_cases.txt marks it), and
#          is not run: the deliberate floor of this list.
#   (run)  it builds, but its output or exit code differs from the golden:
#          the test assumes POSIX (a "/" path, /tmp, sh) or prints what is
#          truly the system's own.
#
# The gate fails on movement in EITHER direction: a program that starts
# passing is a deliberate edit here, in the commit that makes it pass. Beyond
# the (posix) floor, an entry is Win32 platform work still to do.
os_spawn_fds (posix)
os_spawn_signal (posix)
