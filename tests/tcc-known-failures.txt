# Programs the vendored tcc cannot build, and the stage each one fails at.
# Read by `make test-tcc`. One line per program: `<name> (<stage>)`.
#
#   (zc)  zc refuses the program before any C is compiled, naming the unit,
#         what it needs and the toolchain: a unit's `require:` block, or the
#         C backend's `@unit.` row in natives.tbl, speaks for it. This is the
#         finished state.
#   (cc)  nothing speaks for the type yet: tcc rejects the emitted C with a
#         parse error naming a type the program never wrote, in a temp file
#         zc has already deleted. This is what such a refusal exists to
#         replace.
#
# The gate fails on movement in EITHER direction, so a change in what tcc
# accepts is a deliberate edit here rather than a silent one.
#
# Every line below is (zc): each of these programs reaches f128, whose C needs
# __float128, which tcc has none of; the C backend refuses it by name. i128,
# u128 and f16 build under tcc -- a value is a struct there
# (natives/_Z_INT128.inc, natives/_Z_F16.inc) -- so their programs are not
# listed. An error fixture is not listed either: it stops at its own error,
# before emission, where the refusal is made.

# __float128: system's quadfloat subunit, refused by the C backend.
float_widths (zc)
float_mod (zc)
f128_constant_precision (zc)
f128_exponents (zc)
float_functions_wide (zc)

# An emission fixture whose subjects are f16 and f128 constants.
float_constant_emission_wide (zc)

# math's constants as f128.
math_constants_wide (zc)
